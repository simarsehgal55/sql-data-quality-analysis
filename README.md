# SQL Data Quality Analysis

## Project Overview

This project focuses on analysing and improving data quality using SQL, with emphasis on identifying data inconsistencies, missing values, duplicates, and validation issues.

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

## Key Analysis

- Data quality and validation checks
- NULL and duplicate detection
- Data consistency checks
- Referential integrity checks
- Date and data validation
- Business data quality analysis

## Project Files

- `data_quality_analysis.sql` – SQL queries and analysis
- `EER_Diagram.png` – Database schema
- `Data_Quality_Project_Report.pdf` – Detailed project documentation
